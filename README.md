# VUUA Data Analysis Project

![Yearly Max and Min Price](https://i.imgur.com/9SnljDf.png)

## Overview
This project focuses on analyzing VUUA stock price and volume data from January 2020 onwards. The goal is to create basic visualizations for key insights and explore advanced price analysis using PyTorch.

## Data
- Dataset: VUUA stock data starting from January 2020
- Key variables: Price (highest, lowest, average), Volume, Date

## Visualizations in Power BI
The initial phase involves creating basic graphics to understand trends and patterns, including:
- Highest price by month
- Lowest price by month
- Volume traded by year
- Average price per year

These visuals help in preliminary data exploration and provide insights into the stock's behavior over time.

## Price Analysis with PyTorch
Following the visualizations, a tutorial is being followed to use PyTorch for deeper price analysis and modeling. This phase aims to apply machine learning techniques for price prediction or pattern recognition.

## Getting Started
1. Load the VUUA dataset in Power BI for visualization.
2. Use the provided Power BI files (if any) to reproduce the graphs.
3. Follow the PyTorch tutorial to implement price analysis.
4. Integrate insights from both Power BI and PyTorch models for comprehensive analysis.

## Tools Used
- Power BI for data visualization
- PyTorch for machine learning and price analysis
